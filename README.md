# Student Portal

Student Portal is a simple C++ project developed as part of the Git Lab Activity.
## Features

- User login validation
- Calculator functionality
- Simple C++ implementation
## How to Run

Compile the program:

g++ main.cpp -o student-portal

Run the program:

./student-portal

## Project Structure

- `main.cpp` - Main C++ source code
- `.gitignore` - Files ignored by Git
- `README.md` - Project documentation
## Functionality

### Login
The program validates the username and password entered by the user.

### Calculator
The calculator supports:
- Addition
- Subtraction
- Multiplication
- Division
